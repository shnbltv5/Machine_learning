# Python негіздері — шешімдер

Решения 50 заданий по основам Python: переменные, типы данных, условия, циклы, функции.

## Файл

`Python негіздері - шешімдер.ipynb` — ноутбук с заданиями, решениями и выводом каждой ячейки.

## Структура

| Уровень | Задания | Темы |
|---|---|---|
| Бастапқы (начальный) | 1–18 | переменные, арифметика, строки, `if`, списки, словари |
| Орта (средний) | 19–37 | сложные условия, `for` / `while`, обработка списков и словарей, list comprehension |
| Жоғары (высокий) | 38–50 | собственные функции с `return`, разбиение задачи на функции |

## Как запустить

- **Google Colab:** File → Upload notebook → выбрать файл → Runtime → Run all.
- **Локально:** `jupyter notebook "Python негіздері - шешімдер.ipynb"`, затем Run All.

Внешние библиотеки не нужны, только стандартный Python 3. `input()` не используется: все данные заданы в переменных.

## Проверка

Все ячейки выполняются без ошибок. Вывод совпадает с «Күтілетін нәтиже» во всех заданиях, где он указан. В заданиях без готовых данных (12–23) решения проверены на нескольких значениях, включая крайние случаи.
